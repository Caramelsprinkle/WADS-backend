# API-testing with Swagger
Screenshots of testing out old and new endpoints through the Swagger API documentation

![](https://github.com/Caramelsprinkle/WADS-backend/blob/master/API_GetToDo.png?raw=true)
Testing out the Get function for the todo list on the API documentation page. The function gets all Todo list items that have been added to the database in json format when executed

![](https://github.com/Caramelsprinkle/WADS-backend/blob/master/API_Add.png?raw=true)
Testing out the Add new Todo function on the API documentation page. The function has a request body that requires the user to fill in the name of the task, task description, its status, and an image link

![](https://github.com/Caramelsprinkle/WADS-backend/blob/master/API_Delete.png?raw=true)
Testing out the Delete Todo function on the API documentation page. The function deletes a task when selected by their ID in the provided field

![](https://github.com/Caramelsprinkle/WADS-backend/blob/master/API_SignUp.png?raw=true)
Testing out the sign up function on the API documentation page. The function creates a new user to add to the users table which requires the person to fill in various personal information

![](https://github.com/Caramelsprinkle/WADS-backend/blob/master/API_SignIn.png?raw=true)
Testing out the sign in function on the API documentation page. The function checks to see if a user with the provided email and password combination have registered before
